# こっち見ないで!だるま落とし

だるまさんが向こうを向いている間に、何段落とせるか!こっちを向いたら手を止めて。くすぐる・目かくし・ダジャレで だるまさんの気分をあやつる、スリル満点のだるま落とし。

**遊ぶ: https://roguepink.github.io/daruma/**

## あそびかた

- だるまさんが **向こうを向いている間** に、下の大きい「トン!」ボタンで いちばん下の段を叩いて落とす
- かけ声「だるまさんが **ころんだ**」の **赤い字** が出たら手を止める。**こっちを見ている時に押したら おしまい**
- 段は11種類(1回・連打・まと・すべる・ヒビ・2だん・おもち・金・虹・ばくだん・ほし)。色(種類)で点数がちがう
- ちょっかい(くすぐる・ダジャレ・つんつん)で だるまさんの気分を変えられる。見られている間は **だるまさんの顔をタッチで にらめっこ(変顔)**。虹の段から アイテム(目かくし・お茶・**ミステリーボックス**(あけると 5秒むてき か げきおこ!) など9種)
- 段の色で点数がちがう(赤10・灰15・青20・水色10・緑30・黄30・白40・紫50・虹50・黒80・金100)。表は「あそびかた」の4枚目とポーズ画面
- だるまさんは ときどき 早口・フェイント・二度見をする。向こう向きの間に たまに「ちらっ」と チラ見(アウトにはならないけど、叩いていると うたがわれる)
- ちょっかいを使うと だるまさんが「!?」→ こっちを向いて いろんな顔(全部で100)を見せる(そのあいだは トン!しない)。見た顔は「かお図鑑」に集まる
- ときどき 本当にころぶ(叩き放題)・つんつんすると たまにゴールデンだるま(連打でふくらませて ドーン!)・景色が 朝→夜→ご来光へ・通算の段で段位(10級→初段→名人)・結果の「送る」は挑戦状(段数だけ)
- PC: スペース = トン / 1〜3 = ちょっかい / 4 = にらめっこ / 5・6 = アイテム / P = ポーズ / M = 音

## ファイル

- `index.html` 画面の枠・ボタン(タイトル・説明・ポーズ・結果)
- `js/rules.js` きまり(数字・気分・振り向き・段・点数・アウトの判定)。画面や音には さわらない
- `js/game.js` 画面・入力・演出・記録 / `js/daruma-art.js` だるまさん・段・木づち・背景の絵 / `js/audio.js` 音
- 設計は `docs/design.md`、振り向きの確かめは `docs/sim.py`

## 確認用

- アドレスのうしろに `#play` でタイトルを飛ばす(はじめてなら れんしゅう)、`#playreal` で れんしゅうも飛ばす
- `window.DBG.info()` で いまの状態が見られる

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても遊べる

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ
