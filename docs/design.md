# こっち見ないで!だるま落とし — 設計書

2026-11-14 / 元になる企画: `docs/brief.md`(ノブさんの要望) / 振り向きの確かめ: `docs/sim.py`(結果は 11 章)

> この設計書の数字は、そのまま `js/config.js` の CONFIG に入れられるように書いてある。
> 数字を変えるときは `docs/sim.py` の同じ名前の数字も変えて、`python3 docs/sim.py` を流し、

## 0. ひとことで・ゲームの骨組み

- 画面下の大きな **「トン!」ボタン** を押すと、塔の **一番下の段** を木づちで叩く。段が抜けると塔がストンと下がり、下から次の段が来る(上に積み足す=延々と続く)。
- 塔のてっぺんに **だるまさんの頭**。「**だ・る・ま・さ・ん・が・こ・ろ・ん・だ**」と1文字ずつ言い、**最後の「だ」で振り向く**。
- **こっちを向いている間に「トン!」を押したら おしまい**。それ以外は何回失敗しても続く。
- だるまさんには **気分(顔)** があり、気分で言う速さ・止まり方・フェイントがまるで変わる。**ちょっかい** で気分を変えられる。
- 1回のプレイの目安: 初心者 1〜2 分、ふつう 2〜3 分、上手い人 5 分前後〜(11 章のシミュレーション)。

### いちばん大事な約束(フェアさ)

1. **振り向く前には、必ず「ころんだ」(赤い4文字)が出る**。どの気分でも、どの段階でも、**0.60 秒より短くしない**(`TELL_MIN`)。
2. 首が回る **0.12 秒** の間に押したのは **セーフ**(`GRACE`)。だから「赤い字を見てから手を止める」時間は最短でも **0.72 秒**。人の反応(遅い人 0.45 秒)+ 指が止まるまで(0.10 秒)+ スマホの遅れ(0.08 秒)= 0.63 秒 より長い。
3. 一度始まった予兆は **短くしない**(気分が変わっても、アイテムを使っても)。止めた・中断したあとに再開するときは、残りを `TELL_MIN` 以上に戻す。
4. 向こうへ戻る動きが **始まった瞬間から安全**。
5. 「トン!」ボタン **以外** は、こっち向きの間に触ってもアウトにならない(ちょっかいボタン・塔・だるまさん・アイテム)。

## 2. 基本の操作

| 操作 | 決まり | わけ |
|---|---|---|
| 叩く | **「トン!」ボタンを押した瞬間(pointerdown)に 1回**。指を離すのは関係ない | 押した瞬間に反応するほうが気持ちいい・判定がはっきり |
| 押しっぱなし | **何も起きない**(自動の連打はない)。押しっぱなしのままこっちを向かれても **アウトではない**(新しく押していないから) | 自動連打があると「止める」判断がなくなり、このゲームの肝(手を止めるスリル)が消える。押しっぱなしでアウトにすると、指を置いて休んでいた人が理不尽に負ける |
| 2本指で交互 | OK。ただし前のタップから **45ミリ秒** 以内は数えない(`HIT_MIN_GAP`) | 手のひらが触れた・2本同時の二重カウント防止。1秒に22回まで |
| 段をタップ | **叩きにならない**(何も起きない。最初の3回だけ「下のボタンで叩いてね」と出す) | 叩ける場所を1か所にして「このボタンを見られている時に押したらアウト」という決まりを分かりやすくするため |
| ちょっかい・アイテム | 小さいボタンを押す。こっち向きの間は灰色で押せない(押してもアウトにならない)。変顔だけはこっち向きの間に使える | 叩くボタンとは別物、と体で覚えてもらう |
| ポーズ | 左上「‖」・画面が隠れたら自動 | 再開は「3・2・1」。その間 だるまさんは止まり、叩けない。予兆の途中だったら残りを `TELL_MIN` 以上にもどす |

**押しまちがい対策**

- 叩くボタンとちょっかいの間に **24px のすきま**。ボタンの外側 8px までに触れたら、叩きでも ちょっかいでもなく「何もしない」。
- 別のボタンで押し始めて指がすべって叩くボタンに入っても、叩きにならない(数えるのは pointerdown だけ)。
- 段が抜けて塔が下がる **0.12 秒** の間のタップは段に効かない(連打のし過ぎで次の段の回数がずれないように)。**ただし見られていればアウト**(押したことに変わりはない)。
- アウトの判定は、押した瞬間の時刻(`event.timeStamp` をゲームの時刻に直したもの)で行う。画面の1コマのずれでアウトにしない。

## 4. コンボと倍率

- **コンボ** = 今の「向こう向き1回」の中で、続けて落とした段の数。
- コンボの倍率 = `1 + 0.2 ×(コンボ − 1)`、最大 ×3.0(11コンボ)。
- **切れる時**: だるまさんが戻り終わった時(次の向こう向きは 0 から)/ タイミングを外した時。
- **点数** = ベースの点 × コンボの倍率 × 気分の倍率 × すべりこみ(×1.5)× 点数2倍アイテム(×2)。四捨五入。
- 気分の倍率: おこり ×2 / いじわる ×1.5 / なきそう ×1.2 / ほかは ×1。**怒らせるほど もうかるが 危ない**(リスクとリターン)。
- 1回の向こう向きで落とせる段は平均 4.6〜5.2(シミュレーション)。10コンボ超えは「ねむい」「時間止め」の時のごほうび。
- 落とした瞬間に、段のところに「+60」、コンボが5の倍数で「5コンボ!」を大きく出す。

## 5. だるまさんがころんだの仕組み(いちばん大事)

### 5-1. 1回の流れ

```
 向こう向き(SAFE)          予兆(WARN)           振り向き   こっち向き(WATCH)      戻り
 「だ る ま さ ん が」 →  「こ ろ ん だ」(赤) → (GRACE) → 顔を見せる・目が光る → (RETURN) → 次の「だ」へ
  叩いてOK・黒い字         叩いてOK(すべりこみ)   0.12秒     押したらアウト           0.20秒・安全
  1文字ずつ ぽん音         頭がゆれる・音が上がる   セーフ
```

- 向こう向きの長さ = 「だるまさんが」6文字ぶん + 止まり・言い直し。
- 予兆の長さ = 「ころんだ」4文字ぶん(1文字 = 予兆の長さ ÷ 4)。**最後の「だ」と同時に振り向き始める**(伝統の見せ方)。
- フェイント = 「こ ろ…」で止まり「…なんちゃって」→「さんが」から言い直し(3文字)→ 本物の「ころんだ」。
- 二度見 = 戻り終わって 0.35 秒後に「…だっ!」と最短の予兆(0.60秒)でもう一度振り向く(こっち向き 0.6〜1.0秒)。

### 5-2. 予兆の見せ方(全部いっしょに出す)

| 合図 | 向こう向き | 予兆(ころんだ) |
|---|---|---|
| 字 | 黒い字が1文字ずつ。まだの字はうすい灰色で先に見えている(あと何文字か分かる) | 赤い大きい字。1文字ごとにポンと大きくなる |
| 頭 | 少し左右にゆらゆら(気分で変わる) | 左右に小きざみにゆれる(±6度・1秒12回)+ 横顔が少し見える(30度) |
| 音 | 1文字ごとに「ぽん」(音の高さが少しずつ上がる) | 「タタタタ」と速く上がる音。最後の「だ!」で太鼓 |
| 画面 | ふつう | 画面のふちがうっすら赤・叩くボタンが黄→赤に点滅「とめて!」 |
| こっち向き | – | 顔が見える・目がキラッ・ボタン真っ赤「さわらないで!」・ふちが赤 |

- 「ごきげん」は安全だが点数は ×1。安全ばかり選ぶと点がのびない、怒らせると もうかるが危ない、がこのゲームの駆け引き。

## 作る人への注意 10 個

1. **予兆は 0.60 秒より短くしない。** どんな組み合わせ(ばくだん・二度見・本気モード・時間止めのあと・ポーズのあと)でも。数字を変えたら `python3 docs/sim.py` を流し、終わりのコードが 0(理不尽 0・理想の人アウト 0)を確かめる。
2. **アウトの判定は「押した瞬間の時刻」で。** `pointerdown` の `ev.timeStamp` をゲームの時刻に直して `pressHit` に渡す。だるまさんの区間は「はじまり・終わりの時刻」で持ち、`phaseAt(t)` で正確に調べる。次のコマまで待ってから判定しない。
3. **叩けるのは「トン!」ボタンだけ。** 押しっぱなしは何もしない・アウトにもしない。ちょっかい・アイテム・塔・だるまさんに触ってもアウトにしない。ボタンのふち 8px とすきま 24px は「何もしない」。
4. **気分は後ろ姿でも分かるように。** 気分の名前をいつも出し、頭の上のしるし(湯気・zzz・♪・?・ハート)と かけ声のリズムで伝える。顔が見えるのは一瞬なので、後ろ姿こそ作りこむ。
5. **目かくしは、こっち向きの途中で外さない。** 外れるのは向こう向きの間だけ。外れる1秒前から手ぬぐいがずれる絵を出す。
6. **一度始まった予兆を短くしない。** 気分が変わるのは「まだ言っていない文字」から。止めたあと(時間止め・ポーズ・子守歌)に再開するときは、残りの予兆を 0.60 秒以上に戻す。
7. **だるまさんの時間は乱数の種で再現できるように。** `makeRng(seed)` を使い、`Math.random` を直接使わない。不具合が出たとき、同じ種で同じ流れを再生できる。
8. **localStorage は全部 try/catch。** 読めない・書けない(LINE の中・プライベートモード)でも遊べること。画面が隠れたら自動ポーズ+音を止める。再開は「3・2・1」。
9. **音は WebAudio の短い音だけで。** かけ声は声ではなく「ぽん」の高さで表す(機械の声は機種で遅れがばらばらで、振り向きとずれると理不尽になる)。音がオフでも、字と色と頭のゆれだけで完全に遊べること。
10. **点数を強くしすぎない。** パーフェクトは コンボなし・×1、シールドは1つまで、ちょっかい玉は20段に1つ。遊んでみて ごきげん ばかり(退屈)なら `TAMA_EVERY` を上げ、怖すぎるなら下げる。数字を変えたらシミュレーションの表も貼りなおす。
