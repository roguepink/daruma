## 良かったところ

1. **「トン!」ボタンの合図が最高**。358×140 の大きなボタンが、後ろ向き=黄緑「トン!」/予兆=「とめて!」/こっち向き=赤に目のマーク「さわらないで!」/目かくし=うす紫「見えてないよ」/パーフェクト=「連打!連打!」と、**色だけでなく字とマークでも変わる**。画面のふちの赤・かけ声の帯の赤い字も重なって、色が見分けにくい人でも分かる。親指の真下にあり、片手で遊べる。
2. **かけ声の帯「だるまさんがころんだ」が分かりやすい**。まだ言っていない字がうすく先に見えていて「あと何文字で振り向くか」が読める。年配の人でも「だるまさんがころんだ」は体で知っているので、説明いらずで予想できる。
3. **練習がやさしい**。手加減した だるまさん、「いまだよ!トン!トン!」「とめて!」の声、2回まではゆるしてくれる、初めての段で1回だけヒント。いきなり負けて嫌になる人を減らせる。
4. **戻り方が親切**。画面が隠れたら自動で一時停止、再開は「3・2・1 だるまさんは まってるよ」、音のオン/オフはタイトル・ポーズ・右上が全部そろって変わる。
5. **気分が後ろ向きでも分かる**。左上に「きぶん:おこり ×2」(色の丸+字+倍率)、頭の上に ♪・?・湯気 などのしるし。リスクとごほうびが一目で分かる。
6. **結果画面がもう1回遊びたくなる**。「48 段 おとした」が特大、ベストとの差、称号(NEW)、見たかお 3/9 の図鑑、大きな「もういっかい」。
7. **大きい画面・小さい画面でも崩れない**(「とばす」以外)。舞台ごと縮めるので、重なりやはみ出しが起きにくい。

## 合格に必要なこと

1. **アイコン・OGP を だるまさんに描きなおす**(ひな人形を全部なくす。OGP の字の切れも直す)。
2. **プレイ中の字を、論理 16px 以上(実際 14px 前後)にそろえる**。アイテム名は4字以内の呼び名にし、9px をなくす。ちょっかいの値段・段数も大きく濃く。
3. **点滅を1秒2回以下に(できれば点滅をやめて ふくらみ・太いふちで)**。パーフェクトのボタンから赤をなくす。
4. **「変顔」を トン!ボタンから離す**(だるまさんの顔をタップ、がおすすめ)。あわせて「タイトルへ」に確認、結果の「もういっかい」に 0.8 秒のまち。
5. **小さい画面の「とばす」のはみ出しと、ノッチ(セーフエリア)を直す**。
