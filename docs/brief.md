# こっち見ないで!だるま落とし — 企画の土台(ノブさんの要望の整理・2026-11-14)

## ひとことで
**だるま落とし を延々と続けるゲーム** に **だるまさんがころんだ** を組み込む。
だるまさん(一番上の頭)が **向こうを向いている間** だけ、下の段(色つきの胴)を叩いて落とせる。
**こっちを向いているときに叩いたら(落としたら)おしまい**。何段落とせたか(点数)を競う。スリル満点。

## 絶対に入れる要素(ノブさんの言葉どおり)
1. **だるま落としを延々と**: 段はどんどん補充されて終わりがない。終わりは「見られたときに叩いた」とき。
2. **落とし方がいろいろ**:
   - 1回で落とせる段
   - **連打しないと落とせない段**(硬い・重い)
   - **タイミングよく押さないと落とせない段**(ゲージやリングが合ったときだけ)
   - そのほか思いつく種類(すべる・はねかえる・2つ同時・逆向き・爆弾っぽい・金の段 など)
3. **色によって点数がちがう**(例: 赤10・青20・緑30・金100・虹…)。
4. **たまにパーフェクトアイテム**: 使うとしばらく「落としまくれる」(1タップで何段も、自動で…)。遊び心。
5. **だるまさんがころんだ**: だるまさんが こちらを向いている間は押してはダメ。向こうを向いている間に何個落とせるか。**連打している最中に こっちを向かれたら即終了**(スリル)。向く前に予兆(ゆれ・声・音)を出すかはデザイン判断(フェアさ)。
6. **アイテム・操作でだるまさんにちょっかい**(攻撃はしない):
   - **目かくし**(しばらく こちらを向いても見えない)
   - **くすぐる**(笑う → 向き直るのが遅れる?)
   - **意地悪する**(怒る → しばらく怒ったまま、向くのが早く・不規則に)
   - **冗談を言う**(笑う / すべるとムッとする)
   - そのほか遊び心のあるもの
7. **だるまさんの顔をちゃんと描く**(このゲームの主役はだるまさん1人だけ)。顔のパターンをたくさん: **ふつう・笑ってる・怒ってる・意地悪そう・眠そう・泣きそう・照れ・びっくり** など。**顔(気分)によって こちらを向くタイミングが全然ちがう**。
8. こちらの操作で気分が変わる → しばらくその気分が続く(怒ったまましばらく、など)。それが面白くなるように。
